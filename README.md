# Biltong and Bean Co. Website Redesign
An independent website redesign concept for Biltong & Bean Co., built using pure HTML and CSS.

Overview:
This project is a personal website redesign concept based on the existing Biltong & Bean Co. website.

The goal is to rethink the website's user interface and user experience, create a cleaner and more modern visual direction, and improve how the brand and its products are presented online

The UI design will be developed using figma design tool independently before being manually implemented using HTML and CSS.

note: This is also a practical learning project as part of my Week 2 HTML and CSS development practice.

# project goals
- Redesign the website's visual appearance and overall layout
- Create a clear and consistent visual identity throughout the website.
- Improve content hierarchy, spacing, typography and navigation.
- Present products in a more appealing and organised way.
- Build the design manually using semantic HTML and CSS (traditional way)
- Develop a responsive layout for desktop, tablet and mobile screens.
- Practise translating a UI design into a working front-end implementation.

# design & Development
The project follows a design-first approach.
- Website Review: Examine the existing website and identify opportunities for improvement.
- UI Design: Develop a new interface and visual direction independently.
- HTML Development: Build the page structure using semantic HTML.
- CSS Development: Style the interface, including layouts, typography, colours and responsive behaviour.
- Responsive Implementation: Adapt the layout for different screen sizes.
- Review & Refinement: Test the implementation and improve the visual presentation.

# technologies
- FIGMA
- HTML5
- CSS3

note: No CSS frameworks or JavaScript will be used in this project. Everything will be written manually to strengthen my understanding of front-end development fundamentals.

# project scope
This project focuses on the front-end presentation of the website.
It is a static website prototype and does not currently include functional e-commerce features.
